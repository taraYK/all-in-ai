## 它是什么

openGym 是一个可自托管的健身 / 力量训练记录应用。数据存放在你自己的服务器或电脑上，没有订阅、广告和遥测。

## 有什么用

- 记录每次训练的动作、组数、次数和重量
- 内置 5600 多个动作的动作库
- 制定周训练计划，按渐进负荷安排加重
- 有 iOS、Android 和手表端，可在健身房直接记录
- 可从 Strong、Hevy 等应用导入历史数据【待核实具体支持范围】

## 怎么用（Docker Compose 简述）

1. 在服务器或电脑上装好 Docker 和 Docker Compose。
2. 克隆仓库：`git clone https://github.com/DuarteSantos8/openGym.git`，进入目录。
3. 按 README 复制并填写环境变量文件（数据库密码等）。
4. 运行 `docker compose up -d` 启动，浏览器打开 README 中给出的地址和端口。
5. 手机端填自己服务器的地址登录。

不想部署的话，可以先用官网的在线演示看界面。具体命令和端口以仓库 README 为准。

## 可选 AI 教练和 MCP

- AI 教练：可根据训练记录给出计划建议，需要填你自己的模型 API key，费用由你的 API 额度承担。
- MCP：可让外部 AI 助手通过 MCP 读取或操作训练数据，同样用自己的 key。
- 这两项都是可选功能，不开启也能正常记录训练。

## 注意事项

- **许可证 AGPL-3.0**：自用没有限制；如果修改后对外提供服务，需要公开修改后的源码。
- **自托管要自己运维**：包括更新版本、备份数据库、配置 HTTPS；服务器停机时手机端无法同步。
- **健康数据隐私**：训练和身体数据属于个人敏感信息，不要暴露到公网而不设密码，导出的数据不要放进公开仓库。开启 AI 教练或 MCP 后，相关数据会发送给你所用的模型服务商。
- **AI 教练不是医疗建议**：有伤病或体检异常时，以医生意见为准。
