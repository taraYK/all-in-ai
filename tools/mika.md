# Mika：安卓手机上的 AI 助理

> 推荐人：taraYK ｜ 核实日期：2026-10-30 ｜ 来源：[wangzan101/Mika](https://github.com/wangzan101/Mika) 的 README

## 它是什么

Mika 是一个开源安卓 App（Apache-2.0）。你用一句话交代任务，它在手机的一块后台屏上替你操作 App、浏览网页、运行脚本，你可以照常用手机。Mika 没有自己的服务器，请求只发给你配置的模型服务商，模型费用用你自己的 API 额度。目前是早期公开测试版（Beta），作者说主要只在一台安卓 14 手机上测试过。

## 有什么用

- **操作 App**：像人一样看屏幕、点按钮、输入，例如总结微信群当天聊天、总结小红书博主内容、在 BOSS 直聘上给岗位打招呼。
- **内置浏览器**：按电脑版打开网页，能读正文、下载上传，登录状态会保留。
- **定时与条件任务**：例如“每天早上 8 点看天气，下雨才告诉我”。
- **Linux 沙箱**：每个对话一个工作区，可跑 Python、Node、shell 处理文件；默认断网，仅支持 arm64 设备。
- **记忆**：记住你明确说过的偏好，加密存在手机上，可查看和删除。
- **过程可查**：每次任务有过程记录和 Token 用量统计。

对金融研究的可能用法（未实测）：定时整理几个网页的公开信息，或把公众号、微博内容汇总成文字摘要。

## 怎么用

1. **系统要求**：安装需安卓 11+，执行 App 操作任务需安卓 13+，推荐安卓 14+；需要一个支持工具调用的大模型 API Key。
2. **安装**：从 [Releases](https://github.com/wangzan101/Mika/releases/latest) 下载 APK 安装。也可以把手机连上电脑，让电脑上的 AI 助手按 [install-with-agent.md](https://github.com/wangzan101/Mika/blob/main/docs/install-with-agent.md) 帮你装。
3. **配对无线调试（只需一次）**：在 Mika 设置的「设置手机操作」向导里打开开发者选项和无线调试，用 6 位配对码配对，见[设置指南](https://github.com/wangzan101/Mika/blob/main/docs/setup-guide.md)。只用上网、文件和聊天可以跳过这一步。
4. **添加模型**：设置 →「模型」，内置 DeepSeek、通义千问、Kimi、智谱、OpenAI、Anthropic、Gemini、Ollama 等预设，也支持自定义 OpenAI 兼容接口，或用 ChatGPT Plus/Pro 账号登录。主模型必须支持工具调用。
5. **试一试**：例如“帮我总结一下微信群今天都聊了些啥”。

## 注意事项

- **安全提醒（2026-10-31 复核）**：默认「询问」模式只在付款/下单先问你；发消息、发帖、提交表单、删除会直接做。权限含无障碍与无线调试，屏幕内容会发给模型服务商。整体风险偏高，建议用备用机试，不要装在有微信、支付宝、银行和工作账号的主力机上。
- 默认“询问”模式只在花钱的一步先问你，发消息、发帖、提交表单、删除会直接做完；“自主”模式连付款也不问。涉及发送内容的任务要说清范围，并检查结果。
- 登录、验证码、付款密码需要你亲手接管处理。
- 用自动化方式操作第三方 App 可能违反其用户协议，有被限制功能或封号的风险（见 README 免责声明）。
- Mika 会把屏幕内容发给你选的模型服务商，聊天记录、工作资料等敏感内容请自行评估。
- 需要开启无线调试和无障碍权限，权限范围大；APK 从 GitHub 下载，未经应用商店审核。
- Beta 版变化快，升级可能有不兼容改动。
- 【待核实】在其他手机型号上的稳定性、实际 Token 花费、APK 安全性；本页未实际安装试用。核实时仓库 stars 为 0，项目很新。
