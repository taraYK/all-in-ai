# all-in-ai

共享分支，全力拥抱 AI。

这里是我们互相分享好用 AI 工具的地方。发现好工具，就按下面的格式加一行。

## 怎么添加

1. 在 GitHub 网页上打开这个文件，点右上角的铅笔图标（Edit）。
2. 找到合适的分类，在表格最后加一行。
3. 拉到页面底部，点 **Commit changes** 保存。

不想自己改的话，告诉 GitHub助手，让它帮你加。

**格式说明：**

| 工具 | 用途 | 推荐理由 / 使用心得 | 价格 | 推荐人 |
|---|---|---|---|---|
| [工具名](链接) | 一句话说明它干什么 | 你怎么用的、哪里好、有什么坑 | 免费 / 付费 / 部分免费 | 你的名字 |
